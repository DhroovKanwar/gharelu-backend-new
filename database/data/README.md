# pincodes.txt

Every Indian postal pincode (one per line, sorted). Used only to tell a real pincode from a typo when
working out the delivery charge (see `App\Services\PincodeZoneService`); no location data is stored.

Source: pincodes listed in the GeoNames postal code data for India (https://download.geonames.org/export/zip/IN.zip),
licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
